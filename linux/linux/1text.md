## Оснвы Git

### Зачем Git?

#### Почему не флешка?

1. Флешка - потенциальный разносчик вирусов
2. Ваши личные данные могут случайно попасть на чужой компьютер
3. Антивирус может удалить ваши файлы с флешки
4. Флешка может потеряться или сломаться

#### Почему не Yandex или Google диск?

1. Облако Yandex или Google не контролирует версии файлов
2. Ваши данные к Yandex или Google могут случайно остаться на чужом компьютере

### Преимущество Git

1. Трудно потерять свои проекты
1. Легко отслеживать версии проектов
1. Легко делиться с другими людьми вашии проектами
1. Легко вести совместную работу над одним проектом
1. Git - де-факто стандарт в IT и интегрирован почти во все совремеенные технлгии IT (например в VS Code etc.)
1. В Git можно создавать веб-страницы как хотинге
1. Git-сервисы дают возможность автоматизировать сборки и тестирование ваших приложений

### Основные состояния Git-репризитория

1. **Инициализация** - `git status` - показывает текущее состояние репризитория
1. **Подготовка** - `git add .` - пдготовка (добавление) изменений
